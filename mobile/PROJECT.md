# Foundly Mobile App

Foundly is a lost-and-found platform.

People can:
- Report lost items
- Upload found items
- Search items
- Claim ownership
- Earn rewards for returning items

Stack:

- React Native
- Expo SDK 54
- JavaScript only
- React Navigation
- No TypeScript
- Functional components
- Keep code modular
- Use StyleSheet (not NativeWind)

Project structure:

assets/
components/
constants/
navigation/
screens/
services/
utils/

Always follow this structure.

Never create duplicate folders.

Never install packages unless I ask.

Never rewrite existing files unless I request it.

Build screen-by-screen.
